# Матрица сроков хранения TEMLI

**Статус:** рабочий проект для юридической проверки. **Версия:** 2026-09-25.1.

| Категория | Рабочий срок | Удаление |
| --- | --- | --- |
| Профиль преподавателя и настройки | срок договора + 30 дней | из активной системы по окончании срока; из ротационных копий не позднее 30 дней |
| Профиль ученика/родителя, контакты, заметки и ссылки | до удаления преподавателем или достижения цели | из активной системы до 3 рабочих дней; из ротационных копий не позднее 30 дней |
| Будущее и текущее расписание | срок договора или до удаления | как для профиля ученика |
| История проведённых занятий без финансовых сведений | 12 месяцев после занятия, если преподаватель не установил меньший срок | активное удаление по сроку; backups — до 30 дней |
| Стоимость, статус оплаты, операции и сформированные учётные документы | 5 лет после соответствующего отчётного года либо больший обязательный срок, установленный для конкретного пользователя | отдельное архивное хранение; не удаляется по отзыву согласия, если есть самостоятельная обязанность по закону |
| Согласия и доказательства принятия документов | срок обработки + 3 года для защиты правовых требований; окончательный срок проверяет юрист | удаление после истечения срока и отсутствия спора |
| Обращения субъектов и журнал исполнения | 3 года после закрытия обращения | уничтожение по акту/машиночитаемому журналу |
| Журналы безопасности без содержимого сообщений | 90 дней | автоматическая ротация |
| Технические логи с IP/Telegram ID при необходимости расследования | до 90 дней; дольше только по зафиксированному инциденту | автоматическая ротация или закрытие инцидента |
| Резервные копии | 30 ежедневных копий | автоматическая ротация; удалённые записи не возвращаются в рабочую систему при восстановлении |

## Правила

1. Удаление ученика означает немедленную недоступность в интерфейсе и удаление из активной базы в срок до 3 рабочих дней.
2. Финансовая история отделяется от профиля и сохраняется только в минимальном составе, необходимом для учёта и правовых требований.
3. Свободные заметки не предназначены для медицинских, биометрических и иных специальных категорий данных.
4. Дата рождения не входит в утверждённый владельцем перечень данных. Соответствующее поле приложения необходимо отключить до публичного запуска либо отдельно обосновать и внести в документы.
5. После прекращения договора преподавателю предоставляется срок 30 дней на экспорт. Затем оперативные данные удаляются, а финансовые данные сохраняются только при наличии отдельного законного основания.
