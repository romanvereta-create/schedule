## 3. В поддержку proxy-провайдера

**Тема:** Сведения о журналировании SOCKS5/HTTPS proxy для Telegram Bot API

Здравствуйте.

Прошу подтвердить по приобретённому proxy:

- документы сохранены вместе с датой проверки и ответственным лицом.
