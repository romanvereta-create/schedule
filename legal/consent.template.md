# Согласие на обработку персональных данных — отдельный документ

**Статус:** черновик. Согласие нельзя объединять с офертой или пользовательским
соглашением. **Версия:** `[ВЕРСИЯ]`. **Дата:** `[ДАТА]`.

Я, `[ФИО/ИДЕНТИФИКАТОР СУБЪЕКТА]`, свободно, своей волей и в своём интересе
даю `[ОПЕРАТОР И РЕКВИЗИТЫ]` согласие на обработку следующих данных:
`[ИCЧЕРПЫВАЮЩИЙ ПЕРЕЧЕНЬ]` для целей `[КАЖДАЯ ЦЕЛЬ ОТДЕЛЬНО]`.

Разрешённые действия: `[ПЕРЕЧЕНЬ]`; способы: `[АВТОМАТИЗИРОВАННО/СМЕШАННО]`;
получатели/обработчики: `[ПЕРЕЧЕНЬ]`; срок: `[СРОК/УСЛОВИЕ ПРЕКРАЩЕНИЯ]`.

Согласие можно отозвать через `[КАНАЛ]`. Последствия отзыва: обработка,
основанная только на согласии, прекращается, а данные удаляются/уничтожаются в
установленный законом срок, кроме данных, которые оператор обязан или вправе
хранить на ином основании.

## Фиксация в системе

Хранить без изменения: версию и SHA-256 текста, UTC-время, Telegram user ID,
результат отдельного действия «Согласен», язык документа и сведения об отзыве.
Предварительно установленный флажок и продолжение использования без отдельного
действия не применяются.

## Данные ребёнка

Отдельный шаблон должен содержать сведения родителя/законного представителя,
основание полномочий, данные ребёнка в минимальном объёме, цели, срок и канал
отзыва. Способ проверки полномочий определяет оператор совместно с юристом.
